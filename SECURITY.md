# Security policy

This mock repository is not a supported product and should not be used for vehicle-control decisions.

Do not commit:

- private signing or pairing keys;
- GitHub tokens;
- vehicle identifiers;
- captured user video;
- proprietary model weights without authorization;
- credentials from a Comma device.

Security-sensitive reports should be handled privately before a public issue is opened. A private reporting channel has not yet been established.
